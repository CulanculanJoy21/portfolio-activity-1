# Activity 1 – Deployed Portfolio Website

This folder contains a complete responsive multi-page portfolio website built with HTML and CSS.

## Pages
- `index.html` – Home Page
- `skills.html` – Key Skills Inventory
- `goals.html` – Career Goals Portfolio
- `styles.css` – Shared responsive styling

## Before you submit
Open `index.html` and replace these placeholders:
- `your-email@example.com`
- `github.com/yourusername`

You can also adjust any proficiency ratings so they accurately reflect your current ability.

## Deploy with GitHub Pages
1. Sign in to GitHub.
2. Create a new repository, for example `portfolio-activity-1`.
3. Upload all four site files (`index.html`, `skills.html`, `goals.html`, `styles.css`).
4. Commit the files.
5. Open the repository **Settings**.
6. Select **Pages** in the left menu.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Select the `main` branch and `/ (root)` folder.
9. Click **Save**.
10. GitHub will provide your live portfolio URL after deployment.

## Submission proof
Submit the live URL generated by GitHub Pages and verify all three navigation links work on desktop and mobile.
