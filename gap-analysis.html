01

Gap

Full-Stack Backend & API Development

High Priority
Current Position

I have experience with front-end web work and Java-based application development, but I need stronger experience building complete backend services and production-style APIs.

Career Requirement

Full-stack roles require server-side logic, authentication, API design, database integration, validation, error handling, and deployment.

Development Plan

Build at least two complete CRUD applications using a backend framework, REST APIs, authentication, and a relational database. Document and deploy both projects.

Evidence of Progress: Deployed full-stack project + GitHub repository + API documentation.
02

Gap

Cloud Computing & Production Deployment

High Priority
Current Position

I have practiced AWS services through guided labs, including VPC, EC2, S3, IAM, security groups, and related cloud concepts.

Career Requirement

Cloud-focused work requires confidence deploying real applications, managing permissions, understanding cost and security, and troubleshooting cloud environments.

Development Plan

Deploy personal applications on AWS, review architecture fundamentals, and prepare for an entry-level AWS certification such as Cloud Practitioner.

Evidence of Progress: Cloud-hosted project + architecture diagram + certification preparation or completion.
03

Gap

Database Design & Advanced SQL

High Priority
Current Position

I understand SQL fundamentals, but I need more practice designing data models and using databases inside larger applications.

Career Requirement

Software roles require schema design, joins, normalization, constraints, indexes, transactions, backups, query optimization, and secure database access.

Development Plan

Practice MySQL or PostgreSQL through project-based exercises, design schemas from real requirements, and connect databases to full-stack projects.

Evidence of Progress: Database schema / ERD + optimized SQL queries + database-backed application.
04

Gap

Cybersecurity Fundamentals

Medium–High
Current Position

I have foundational awareness through networking, IAM, and security-related coursework, but limited hands-on security testing experience.

Career Requirement

Developers and cloud professionals need secure authentication, access control, safe configuration, OWASP awareness, vulnerability management, and security-minded development.

Study OWASP fundamentals, Linux permissions, IAM, secure networking, and beginner vulnerability-assessment labs using legal training environments.

Evidence of Progress: Security course certificate + documented secure-coding checklist + lab reflections.

Gap

DevOps, Docker & CI/CD

Medium Priority
Current Position

Career Requirement

Modern development teams expect familiarity with branches, code review, Docker, environment configuration, CI/CD pipelines, and automated deployment.

Development Plan

Containerize a personal project with Docker, build a GitHub Actions workflow, and automate testing or deployment from the repository.

Evidence of Progress: Dockerfile + GitHub Actions workflow + automated deployment demonstration.
